FUT04 Furnace Code drum kit, from Wubansia

FUT04's drums as Wubansia plays them: dark industrial / techno, 136 BPM, E minor (9A), content v1. Every WAV here is the kit's own 48 kHz / 24-bit file, byte for byte.

IN THIS FOLDER
- Pads: one WAV per drum note, its loudest hit, for your drum rack's pads.
- Samples: every velocity layer (v1 is the softest) and round robin (rr1, rr2...) of each pad, for the SFZ files.
- FUT04 Furnace Code Drum Kit.sfz: the whole kit for an SFZ player.

THE PADS
Wubansia's drum MIDI plays these notes, on channel 10: the Loop and Song drags, the Drums part and 1 drum track. Notes are named as in Live and Logic, where middle C is C3, so 36 is C1.

  Note    Sound        Level     Pan        Plays
  35 B0   Rumble       -14.4 dB  centre     loops while the note is held, 5 ms release, each note restarts the loop; seamless at the kit's 136 BPM
  36 C1   Kick Split   -2.7 dB   centre     one-shot
  38 D1   Snare Gated  -0.8 dB   centre     one-shot
  42 F#1  Closed Hat   -3.7 dB   15% right  one-shot, cuts the open hat
  46 A#1  Open Hat     -3.7 dB   15% right  one-shot, cut by the closed hat over 4 ms
  47 B1   Anvil        -6.3 dB   25% left   one-shot
  51 D#2  Ride         -14.8 dB  centre     one-shot

Level and pan are each sound's channel fader and pan in Wubansia's mix, which the SFZ files apply. The rest of that mix (EQ, ducks, sends, the drum bus, the club master) isn't here: these are the dry sounds.

IN ABLETON LIVE
1. Put a Drum Rack on a MIDI track.
2. Drag each file in Pads onto its note's pad: each name starts with its note. Files dropped together fill pads in a row from the one you drop on, so drop them one at a time.
3. Set each pad's volume and pan from the table, put the hats in one choke group, and save the rack as a preset.
4. The rack shows C1 to D#2 at first: scroll its pad overview for B0.
5. Set the looped sound's Simpler to Gate, so the note's length plays it.

IN LOGIC PRO
1. Make a Drum Machine Designer track.
2. Drag each file in Pads onto a pad, and set the pad's input note to the note in the table.
3. Put the hats in one choke group, and save the patch.
4. Set the looped sound's Quick Sampler to Classic, so the note's length plays it.

IN AN SFZ PLAYER (sfizz, sforzando, Bitwig Studio's Sampler)
Load an .sfz file here, beside the Samples folder. It maps every layer and round robin, the levels, the pans and the hat choke, and plays the drum MIDI as Wubansia does.

YOUR OWN SOUNDS
Swap a pad's file for your own sample in your DAW. For the SFZ files, put your file in Samples under the name it replaces, or point that pad's sample= lines at your file.

THIS FOLDER IS YOURS
Wubansia never changes or deletes anything in it. If you change it and save the drum kit again, Wubansia saves a fresh copy beside it, "FUT04 Furnace Code Drum Kit (2)".
